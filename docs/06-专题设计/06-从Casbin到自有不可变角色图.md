# 从 Casbin 到自有授权快照

> 状态：已实现 · 本轮代码已实现，生产数据切换与业务验收另行记录。

IAM 已退役 Casbin。当前进一步退役角色继承和条件授权，使用直接 Assignment 找到角色，对多个角色的 PermissionGrant 取并集并匹配资源、动作。

权限事实只有角色、分配、目录和 Grant；运行时索引是可重建投影。原生模型避免字符串 policy 与领域事实双写，保留匹配 Grant、PolicyVersion、敏感保护和可审计管理入口。

快照原子发布并维护版本、新鲜度和加载健康。加载失败不发布部分策略；残留条件数据不能被解释为无条件 Grant。业务机构、关系、状态和查询范围由业务系统检查。

历史 Casbin、继承及条件迁移分别保留原有审计证据。本轮条件退役采用独立清单与兼容契约，详见 [维护手册](../02-业务模块/03-AuthZ/08-条件授权退役维护手册.md)。Scope 保持独立后续设计。
